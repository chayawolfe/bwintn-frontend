# BWINTN Frontend

BWINTN is a modern betting and casino frontend built for a high-conversion online gaming experience. The interface is designed to feel premium, fast, and conversion-focused, with a layout that supports sportsbook browsing, live betting, casino promotions, wallet actions, and user account management.

This project is structured to deliver a polished experience for desktop and mobile users, with reusable UI sections and a scalable architecture for future growth.

## Brand Direction

BWINTN is positioned as a clean, confident, high-performance betting platform. The frontend focuses on:

- strong sportsbook visibility and event discovery
- premium casino and game showcase sections
- promotional landing areas and bonus presentation
- fast, intuitive navigation for users
- secure-looking wallet and account flows
- modern visual styling with a strong conversion mindset

## Core Features

- Sports betting dashboard with match listings and odds display
- Casino and gaming landing pages
- Promotional banners and campaign modules
- User account, wallet, and profile screens
- Transaction, deposit, and withdrawal UI flows
- Multi-language support with i18n architecture
- Responsive layout and modular component design
- Reusable theme and styling system

## Tech Stack

- React 18
- TypeScript
- React Router DOM
- Material UI (MUI)
- Axios
- i18next
- Framer Motion
- Custom CSS and theme styling
- React-Scripts

## Requirements

- Node.js 16.x or 18.x
- npm or yarn

## Installation

### Yarn

```bash
yarn install
yarn start
```

### npm

```bash
npm install
# or
npm install --legacy-peer-deps
npm start
```

## Production Build

```bash
npm run build
```

## Notes
